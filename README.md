# Sentiment Analysis API

A Web API built with **FastAPI** that serves a **Hugging Face** sentiment analysis model.
Send English text to the API and get back `POSITIVE` or `NEGATIVE` with a confidence score, as JSON.

## 2. Selected Model

- **Model:** `distilbert/distilbert-base-uncased-finetuned-sst-2-english`
- **Hugging Face page:** https://huggingface.co/distilbert/distilbert-base-uncased-finetuned-sst-2-english
- **Task:** Sentiment analysis (text classification)

DistilBERT is a smaller, faster distilled version of BERT. This checkpoint is fine-tuned on the SST-2 dataset (movie review sentiment) and predicts one of two labels: `POSITIVE` or `NEGATIVE`.

## 4. Installation

Requirements: Python 3.10 or newer (developed and tested with Python 3.13 on macOS, CPU only).

```bash
# 1. Clone the repository
git clone <YOUR_GITHUB_REPO_URL>
cd <REPO_FOLDER>

# 2. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate          # macOS / Linux
# .venv\Scripts\Activate.ps1       # Windows PowerShell

# 3. Install dependencies
pip install -r requirements.txt
```

The first run downloads the model (about 270 MB) from Hugging Face and caches it locally, so the first start is slow.

## 5. Running the Application

```bash
uvicorn main:app
```

Wait for `Application startup complete`, then open:

- API root: http://127.0.0.1:8000/
- Interactive documentation (Swagger UI): http://127.0.0.1:8000/docs

## 6. Calling the API

### GET /

```bash
curl http://127.0.0.1:8000/
```

Response:

```json
{
  "name": "Vo Le Nam Khanh Ann - 25127274",
}
```

### GET /health

```bash
curl http://127.0.0.1:8000/health
```

Response:

```json
{"status": "ok"}
```

### POST /predict: positive example

Request:

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "I love this course!"}'
```

Response (`200 OK`):

```json
{
  "text": "I love this course!",
  "label": "POSITIVE",
  "score": 0.9999
}
```

### POST /predict: negative example

Request:

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "This was a terrible experience."}'
```

Response (`200 OK`):

```json
{
  "text": "This was a terrible experience.",
  "label": "NEGATIVE",
  "score": 0.999
}
```

`score` is the model's confidence in the predicted label, between 0 and 1.

### Using Python (requests)

```python
import requests

r = requests.post(
    "http://127.0.0.1:8000/predict",
    json={"text": "I love this course!"},
)
print(r.status_code, r.json())
```

## 7. Error Handling

| Situation | Status code | Handled by |
|---|---|---|
| Missing `text` field | 422 | Pydantic validation |
| `text` is not a string | 422 | Pydantic validation |
| Empty text | 422 | Pydantic validation |
| Whitespace-only text | 422 | Custom validator |
| Text longer than 2000 characters | 422 | Pydantic validation |
| Malformed JSON body | 422 | FastAPI |
| Model inference failure | 500 | `try/except` in `/predict` |

Example: empty text

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": ""}'
```

Response (`422 Unprocessable Content`):

```json
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["body", "text"],
      "msg": "String should have at least 1 character",
      "input": "",
      "ctx": {"min_length": 1}
    }
  ]
}
```

Example: missing field (`{}`)

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "text"],
      "msg": "Field required",
      "input": {}
    }
  ]
}
```

## 8. Testing

Start the server in one terminal (`uvicorn main:app`), then run the test script in another:

```bash
python test_api.py
```

The script uses the `requests` library and runs 11 tests: the `GET /` and `GET /health` endpoints, positive, negative and long inputs, and six invalid-input cases (empty, whitespace-only, missing field, wrong type, too long, malformed JSON).
